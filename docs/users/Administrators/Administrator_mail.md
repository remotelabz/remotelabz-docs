# Mail

![Screenshot](/images/mail/Mail.png)

Since RemoteLabz 2.4.4, there is a functionality which allows you to send a mail to any RemoteLabz user using their account's email address.
To send, just choose the account, write your text and then click on submit.
Once done, the mail sent notification should appear.

!!! tip
    There is an all-users flag which allows broadcasting a mail to all existing RemoteLabz accounts.

!!! warning
    Only an administrator can use this functionality.
