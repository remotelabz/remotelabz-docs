# Instance management

From this panel, you can manage all instances that are running on the server including those from other users. You can retrieve labs, device or instance by UUID.

![Screenshot](/images/Administrator/Instance/Administrator_instance.png)

To see more details about an instance, click on the `Details` button. A pop-up will show up.
![Screenshot](/images/Administrator/Instance/Administrator_instance_details.png)

From there, you have access to all informations about the instance, you can :

* See the owner of the instance
* Start all, stop all and reset all devices 
* Start, stop or reset one device
* Leave the lab


!!! Warning
    The button `Leave lab` destroys all instances running on the server.
