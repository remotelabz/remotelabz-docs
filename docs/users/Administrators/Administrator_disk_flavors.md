#Disk Flavor management

Disk flavors define the storage capacity for blank operating systems.
![Screenshot](/images/Administrator/Disk_Flavor/Administrator_disk_flavor_management.png)

##Disk Flavor creation
You can add a new `Disk Flavor` by clicking on the new disk flavor button.
![Screenshot](/images/Administrator/Disk_Flavor/Administrator_new_disk_flavor.png) 

Here, you must fill in the fields as follows : 

 * **Flavor Name** : name of the new Disk Flavor.
 * **Disk Size** : size in gigabytes.

##Disk Flavor edition
![Screenshot](/images/Administrator/Disk_Flavor/Administrator_edit_disk_flavor.png)
 Pressing on the `Edit` button will brought the disk flavor edit's screen which will allow you to edit the Disk Flavor's values.
