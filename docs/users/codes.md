# Lab code

In RemoteLabz 2.4.4, a user can access a lab by using a specific code issued by their administrator or a teacher.

!!! warning
    Only an administrator or a teacher can create a lab code.
    See [Lab code creation (Teacher)](Teachers/Teachers_codes.md) or [Lab code management (Administrator)](Administrators/Administrators_codes.md) for more details.

## Lab code use

To use a lab code, go to the login page and click on `Login with code`.

![Screenshot](/images/codes/lab_code_login.png)

Then enter the code you were given and click on `Sign-in`.

![Screenshot](/images/codes/lab_code_login_access.png)

Afterwards, you will be redirected to a specific session where only the specified lab can be joined.

![Screenshot](/images/codes/lab_code_lab_access.png)
